# 0x1A. Hash tables

## Description
Implementation of a hash table in C using chaining for collision handling.

## Files
- `0-hash_table_create.c` - Creates a hash table
- `hash_tables.h` - Header file containing the data structures and prototypes

## Requirements
- Allowed editors: vi, vim, emacs
- All files compiled with `gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
- Code follows Betty style
